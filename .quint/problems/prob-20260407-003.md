# Artifact registry pillar for overnight pilot

## Signal

Plans, prompts, traces, verdicts, and bulky outputs need a discoverable home for morning review without building a second Langfuse.

## Constraints

- Pilot must avoid heavy new infrastructure
- Must not duplicate Observability pillar trace UI unnecessarily
- Reproducibility tied to git SHA where possible

## Optimization Targets

- Human-queryable run history
- Clean split: metadata vs blobs

## Acceptance

Directory or schema convention documented; at least one pilot run leaves a manifest linking artifacts to commit.
