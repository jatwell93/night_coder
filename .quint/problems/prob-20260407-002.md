# Secrets and IAM pillar for overnight autonomous coding

## Signal

Provider API keys and bootstrap credentials must not live in repo or plain CI YAML; rotation and least-privilege boundaries are undefined for the pilot.

## Constraints

- Headless CI and overnight runners
- Solo-operator manageable ops
- User preference to evaluate Doppler seriously
- Secrets must not leak into Langfuse traces or git by default

## Optimization Targets

- Single source of truth with minimal bootstrap secrets
- Clear rotation path for v1

## Acceptance

One documented pattern: how the agent and CI obtain keys; one service token or equivalent per trust boundary; redaction rules stated.

## Blast Radius

All external APIs, CI, local dev

## Reversibility

high
