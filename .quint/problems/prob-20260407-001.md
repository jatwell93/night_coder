# Execution sandbox pillar for overnight autonomous coding

## Signal

Agent tasks need deterministic isolation for shell, filesystem, and network on a solo Linux VPS (~4GB) without Kata-scale RAM cost.

## Constraints

- Must work headless overnight
- Budget VPS; avoid VM-per-task as default
- Composable with Ralph + NTM; agent must not escape policy accidentally
- Rollback must be operational not architectural

## Optimization Targets

- Predictable per-task blast radius
- Low ops burden for solo operator

## Acceptance

Named execution profiles exist (offline vs online); default path documented; one pilot run completes inside chosen isolation.

## Blast Radius

Runner host, compose, CI

## Reversibility

high
