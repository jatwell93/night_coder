# Git-native run manifests (pilot) with Langfuse for LLM traces

## 1. Problem Frame

**Signal:** Plans, prompts, traces, verdicts, and bulky outputs need a discoverable home for morning review without building a second Langfuse.

**Constraints:**
- Pilot must avoid heavy new infrastructure
- Must not duplicate Observability pillar trace UI unnecessarily
- Reproducibility tied to git SHA where possible

**Acceptance:** Directory or schema convention documented; at least one pilot run leaves a manifest linking artifacts to commit.

## 2. Decision

**Selected:** Git-native run manifests (pilot) with Langfuse for LLM traces

Zero new services for pilot; clear separation — Langfuse remains source of truth for LLM/runtime telemetry while git holds reviewable plans, verdicts, and machine-readable summaries tied to commit SHA.

**Invariants:**
- Each run writes a manifest with run id, timestamps, git SHA, pointers to large artifacts
- Langfuse stores LLM traces; registry stores durable human-facing verdicts and plans unless explicitly mirrored
- Large binaries never committed raw without DVC/LFS/remote URI

**Pre-conditions:**
- [ ] Directory convention agreed under docs/superpowers/pilot or successor

**Post-conditions:**
- [ ] At least one pilot run recorded with manifest + verdict path
- [ ] Morning review path documented (git log / rg)

**Admissibility:**
- NOT: Treating Langfuse as the only archive for contractual verdict text without git mirror
- NOT: Committing multi-megabyte traces to plain git

## 3. Rationale

| Variant | Verdict | Reason |
|---------|---------|--------|
| Git-native run manifests (pilot) with Langfuse for LLM traces | **Selected** | Zero new services for pilot; clear separation — Langfus... |
| SQLite catalog + object pointers | Rejected | Stepping stone when run volume grows; defer until grep/git log is insufficient. |
| MLflow-style tracking server | Rejected | Ops weight and overlap with Langfuse observability make it poor default for this stack. |

**Weakest link:** Human-scale query only until SQL catalog is added.

**Evidence requirements:**
- One merged example run folder in repo or documented external path
- Manifest validates against schema

## 4. Consequences

**Rollback plan:**
Triggers:
- Convention blocks velocity
Steps:
1. Stop writing manifests; rely on ad hoc logs

**Refresh triggers:**
- >N runs/week make grep painful
- Need cross-run analytics dashboard
